O que é HTML?

HTML, ou HyperText Markup Language (Linguagem de Marcação de Hipertexto), é o código base utilizado para estruturar e criar a estrutura visual de páginas web, organizando elementos como textos, imagens, links, parágrafos e tabelas. Ele funciona através de tags que dizem aos navegadores (Chrome, Firefox, etc.) como exibir cada parte do conteúdo, formando o esqueleto dos sites.

Estrutura básica de um documento HTML

Um documento HTML é composto por várias partes essenciais que definem sua estrutura e conteúdo. A seguir, estão os principais componentes:

                <!DOCTYPE html>: Declara o tipo de documento e a versão do HTML utilizada.
                <html>: Elemento raiz que envolve todo o conteúdo da página.
                <head>: Contém metadados, links para estilos, scripts e o título da página.
                <meta charset="UTF-8">: Define a codificação de caracteres para o documento.
                <title>: Define o título da página que aparece na aba do navegador.
                <body>: Contém todo o conteúdo visível da página, como textos, imagens e links.

Exemplo de estrutura básica de um documento HTML:

                <!DOCTYPE html>
                <html lang="pt-br">
                <head>
                    <meta charset="UTF-8">
                    <meta name="viewport" content="width=device-width, initial-scale=1.0">
                    <title>Título da Página</title>
                </head>
                <body>
                    Conteúdo visível da página
                </body>
                </html>

Tags e atributos

As tags são elementos que definem a estrutura e o conteúdo de uma página HTML. Cada tag tem um propósito específico e pode conter atributos que fornecem informações adicionais sobre o elemento. Por exemplo, a tag `<img>` é usada para inserir imagens, e pode ter atributos como `src` (para especificar o caminho da imagem) e `alt` (para descrever a imagem em caso de falha no carregamento).

Exemplo de tag com atributos:

            <img src="caminho/para/imagem.jpg" alt="Descrição da imagem"> aqui o conteúdo visivel da página <img/>

Elementos semânticos

Elementos semânticos são tags HTML que descrevem claramente o significado do conteúdo que elas envolvem, tanto para os desenvolvedores quanto para os navegadores e mecanismos de busca. Exemplos comuns de elementos semânticos incluem `<header>`, `<nav>`, `<article>`, `<section>` e `<footer>`. Esses elementos ajudam a estruturar o conteúdo de maneira lógica e melhoram a acessibilidade e SEO (Search Engine Optimization) das páginas web.

Exemplo de uso de elementos semânticos:

            <header>
                <h1>Título da Página</h1>
            </header>
            <nav>
                <ul>
                    <li><a href="#">Link 1</a></li>
                    <li><a href="#">Link 2</a></li>
                </ul>
            </nav>
            <article>
                <h2>Título do Artigo</h2>
                <p>Conteúdo do artigo...</p>
            </article>
            <footer>
                <p>Rodapé da página</p>
            </footer>
